# Ismail Samani

Berilgan dizayn ekranlaridan yig'ilgan mobil veb-prototip. Bosh sahifa, menyu, kapuchino tafsilotlari, savatcha, profil, buyurtmalar tarixi va bildirishnomalar o'zaro bog'langan.

## Ishga tushirish

Loyiha ildizida `python3 -m http.server 8000` buyrug'ini ishga tushiring va `http://localhost:8000` manzilini oching. Internet aloqasi kerak: dizayn Tailwind CDN, Google Fonts va tashqi rasmlardan foydalanadi.

Bu prototip: savatcha, buyurtmalar va to'lov ekranlaridagi ma'lumotlar namunaviy, backend yoki haqiqiy to'lov tizimiga ulanmagan. Faqat kapuchino uchun alohida mahsulot tafsilotlari dizayni mavjud.
